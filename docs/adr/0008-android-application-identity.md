# ADR 0008 — Android application identity

## Status
Accepted

## Decision

Application name:

Chuleta C1

Android / Capacitor App ID:

es.mrabeh.chuletac1

## Rationale

El identificador debe ser estable y único porque será utilizado como
applicationId/package identifier en Android y Capacitor.

No debe modificarse una vez que la aplicación se publique en Google Play,
salvo migración explícita a una aplicación distinta.
